# Gachipunk3Season
Руководство разработчикам.
Для добавления новеллы в ваш движок Renpy, настройки синхронизации Github и нашего удобства:
1. После того как вас добавили в соавторов проекта откройте GitHub Desktop (если его нет, то скачайте с https://desktop.github.com и войдите в свой аккаунт в приложении).
2. Добавьте в текущие репозитории проект (нажмите на current repository, затем add и clone repository).

![image](https://github.com/GachipunkProduction/Gachipunk3Season/assets/151411352/892d78d1-6b32-4e70-8d30-fff92b6a02f7)

3.а. Выберите в your repositories "Gachipunk3Season", укажите в local path путь к project в папке, находящейся выше корневой папки движка Renpy на вашем компьютере и нажмите clone.

![image](https://github.com/GachipunkProduction/Gachipunk3Season/assets/151411352/751f5823-38ab-45ee-86e8-7e892da5ebce)

3.б Если в your repositories нет репозитория "Gachipunk3Season", то перейдите в окно url и в первое поле введите https://github.com/GachipunkProduction/Gachipunk3Season.git или gh repo clone GachipunkProduction/Gachipunk3Season, а в local path как в пункте выше. Нажмите clone.

![image](https://github.com/GachipunkProduction/Gachipunk3Season/assets/151411352/88ac9678-af89-4f9a-80f2-382f5ba75bb1)


4. После клонирования репозитория выберите ветку (branch) develop. Для теста экспериментальных функций, способных накрыть проект медным тазом, используйте ветку experimental.

![image](https://github.com/GachipunkProduction/Gachipunk3Season/assets/151411352/f6cba8e6-7cab-4d82-9743-33dc335f2787)
